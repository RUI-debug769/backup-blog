# inbox — 微信来稿收件箱

把从微信里想变成博客的内容放进这个目录，然后对 Claude 说「整理收件箱」。

## 怎么放

- **一段文字**：新建 `.txt` 或 `.md`，直接粘贴原文保存。
- **一篇公众号文章**：粘贴正文即可；也可以只放链接（能抓就抓，抓不到会告诉你）。
- **带图**：图片另存到 `public/assets/posts/<slug>/`，正文里写 `![](/assets/posts/<slug>/xxx.jpg)`；不确定就先不写图，整理时会问你。

## 命名

`YYYY-MM-DD-简短标题.md`，例如 `2026-10-31-纳瓦尔与智能的拟合.md`。
文件名只是为了排序和辨认，最终 slug 由整理流程决定。

## 整理完会怎样

原文会被移到 `inbox/_done/` 归档，成稿先写到 `drafts/` 等你确认。
`inbox/` 和 `drafts/` 都在站点源码目录之外，不会被打包进网站。
