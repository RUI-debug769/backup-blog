# drafts — 成稿前的草稿区

这里放还没确认入库的文章。目录不在 `src/` 下，**不会被打包进网站**。

## 流程

1. `inbox/` 的原文或一次采访，整理成 `<日期>-<slug>.md` 放这里
2. 你在对话里看标题、摘要、结构，提修改意见
3. 定稿后我把它移进 `src/content/posts/`（或 `src/content/moments/`），再跑构建验证
4. 构建通过后由你决定是否提交推送

## 草稿自带的两块东西

- **改动说明**：正文之后单独一段，写清改了什么、删了什么、为什么不保留，确认时一眼能看完
- **原文留档**：`drafts/` 里保留完整原文，成稿里只在需要时放折叠块

草稿不是最终稿，允许结构推翻重来；一旦移进 `src/content/` 就按正式内容对待。
