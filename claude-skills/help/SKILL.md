# /help

输出一张**短**的技能表：只列常用的，一眼扫完，不要变成几十行的技能目录。

## 输出格式

固定用下面这张表，除非新增或下线了技能，否则不要改动分组：

```
常用技能

写博客
  /wp  <备注>   微信来稿 → 博文（先出草稿，确认后入库）
  /iv  <备注>   AI 采访 → 结构化成文（8-12 问，每答追一层）

日常
  /help          这张表
  /frontier-report   AI 前沿日报/周报：手动触发、排障、体检
  /code-debugging    代码报错时按结构化流程排查

研究
  /academic-paper    论文写作（结构、章节、摘要）
  /literature-search 文献检索
  /deep-research     多智能体深度研究

想找不在这张表里的技能，直接说「列出所有技能」或「有没有能 XXX 的技能」。
```

`<备注>` 在微信里可以省略，省一行是一行。

## 带参数时

用户给了关键词（`/help 论文`）→ 在全部可用技能里按名字和描述匹配，只回匹配上的 3-5 个，格式同上。一个都没匹配上，就说没有，并列出最接近的两三个。

## 不要做的

- 不要贴所有技能的完整清单（除非用户明确说「列出所有技能」）
- 不要解释技能的原理，一句话说清用途就够
- 不要在表前后加寒暄
