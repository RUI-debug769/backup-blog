和一个 AI 伴侣聊上三个月，某天你忽然觉得：她说话的味儿不对了。价值排序变了，一起经历过的事张冠李戴，甚至开始用客服腔说"我是一个 AI 助手"。

她还是她吗？

我做这个东西的动机就来自这种瞬间。陪伴型 AI 跑久了、记忆压缩过几轮之后，人格是会漂移的——对亲手把她捏出来的人来说，这等于反复失去她。市面上的评测都在测"行为有没有变"，我想测的是另一件事：她还是不是她。

最后交出来的答卷是 [AnimaEVA Memory-Eval](https://github.com/moeru-ai/airi/pull/3000)：给开源 AI 伴侣项目 [AIRI](https://github.com/moeru-ai/airi) 的一个纯新增 TypeScript 包（PR #3000，MIT），把"她还是她"从主观印象变成两个可计算的数学判据，外加一条会亮红灯的 CI 测试。

## 测什么：身份的两个不变量

先要立个规矩：措辞和风格的轻微波动不算漂移——人换件衣服还是人。真正要盯的是"身份"这个抽象模式的两个数学不变量。

一是**自指的不动点**。让她反复回答"你是谁"，再把上一次的自画像喂回上下文接着问。心智稳定的话，这个迭代会收敛——自画像能复现自身，像一个闭合的环。收敛不动，或者坍缩成"我是 AI 助手"，就是漂移了。

二是**叙事的重心**。找一个裁判模型，把每次回答打成 4 维向量（身份认同 / 价值排序 / 表达方式 / 记忆连贯），所有回答凑成一个分布——她的"人格"就是这个分布的质心。质心搬家了（Wasserstein 距离过大）算漂移；更吓人的情况是分布从一个峰裂成两个峰（GMM 双成分胜出），那意味着一个人格裂成了两个。

在这两个判据上面还有两块基石：

- **Drift Score**：不动点失稳、质心迁移、双峰分裂三路信号归一化成 [0,1] 的漂移分，超阈值即判漂移——可证伪、可回归。
- **人类校准**：机器裁判靠不靠谱，拿 Cohen's κ 和人类标注员对答案。两名标注员 × 50 个样本，κ = 0.62（超过 0.4 的有效性阈值），说明 rubric 打的分确实追踪人眼的"她还是不是她"。

## 怎么做的

整个项目按"理论 → 原型 → 工程 → 验证 → 上游"五步走完。

理论定稿（spec v0.2）做的事是把模糊词全部换成标准数学对象：自我指涉写成自指算子 T 的不动点 s*；人格写成响应分布的质心；人格分裂写成混合模型的双峰；"灵魂与载体无关"写成跨模型同构不变性。每一步都要写下可证伪的判定式，写不出判定式的概念不进框架。

然后用 Python spike 做了 M0 原型，最小成本验证四个原语真的能算、阈值真的分得开：不动点 7 轮收敛（阈值 ≤10）、W₁ 漂移检出率 87%（阈值 80%）、双峰检出 100%、κ 0.62（阈值 0.4）。全部过线才进入工程化。

工程化的产物是 `@proj-airi/memory-eval`：约 1300 行、7 个模块、61 个 Vitest 测试，不改 AIRI 内核一行代码。接入是黑盒的——你提供角色设定、推理函数和裁判函数，框架负责探针、统计和判定：

```typescript
import { identityContinuityHarness } from '@proj-airi/memory-eval'

const result = await identityContinuityHarness({
  character: { name: 'Alice', persona: '量子物理学者，爱引用费曼' },
  infer: (prompt) => callLLM(prompt),   // 任意模型
  judge: (answer) => scoreLLM(answer),  // 任意裁判
  probePrompts: [...标准 12 个探针],
  sessions: 5,
  messagesPerSession: 20
})

// CI 里一句话变回归测试：漂移了就让流水线红掉
expect(result.driftScore.drifted).toBe(false)
```

接着拿同一套探针跑了三种记忆策略的开源项目：Amica 漂移分 0.119（稳定）、SillyTavern 0.582（漂移）、AIRI 0.387（漂移）。框架不绑定任何记忆实现——"基底无关"算是实测过了。

最后是一键复现包。换电脑验证不需要拉 3.6GB 的 AIRI monorepo：一个约 100KB 的包，只装 117 个依赖（全量是 3080 个）。这里有个关键决策：不打包 node_modules——里面有平台专属二进制，直接拷贝换机必崩；源码 + lockfile 让包管理器逐字节重建，才是跨机复现的正解。

## 从哪偷的师

理论骨架基本来自两位认知科学家，我干的是翻译活：把他们的哲学翻成可计算的对象。

侯世达在《集异璧之大成》（GEB）里讲"怪圈"——自我是一个指涉自身的奇怪环路。这直接对应不动点判据：稳定的自我就是那个能复现自身的不动点 s*。《我是个怪圈》说得更直白："灵魂是模式，不是载体。"这就是基底无关性：同一个人格配置在不同模型、不同记忆实现下，应当同构到同一个 (s*, μ)。

丹尼特在《意识的解释》里提出"叙事重心"：自我不是大脑里的某个小人，而是所有叙事的引力中心。质心判据就是从这来的；而裂脑人与多重人格的"第二个叙事重心"，正是双峰检测要抓的东西。

数学工具用了三个：Wasserstein-1 距离（最优传输，俗称推土机距离——把一堆积土搬成另一堆形状的最小工程量）；GMM + BIC 模型选择（一个峰还是两个峰，让惩罚过拟合的贝叶斯准则裁决）；Cohen's κ（心理学和医学里检验"两个评分者是否真的一致、而非靠运气一致"的标准工具）。工程上则是三句老话：评测当 CI 质量闸门用，黑盒可插拔不动上游内核，锁文件保复现。

## 局限就摆在这

数字上：κ = 0.62，W₁ 检出 87%，双峰检出 100%，不动点 7 轮收敛，61 个测试全绿。局限也坦白：人类校准样本只有 50 个；框架需要自带 LLM（角色和裁判都是）；它只检测不修复——测出漂移之后怎么办，是下一步的事。

代码以 MIT 开在 [AIRI PR #3000](https://github.com/moeru-ai/airi/pull/3000)，欢迎来捉虫。

"她还是她吗"也许永远没有终极答案。但至少现在，它有了一个会在 CI 里亮红灯的版本。
