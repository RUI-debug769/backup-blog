想认真讨论一个问题——"自由意志是否存在""要不要辞职考研"——翻遍通讯录找不到能交锋的对手。去问 AI，它说："您说得对，这个问题确实值得深思。"

附和是思考的死敌。1902 年，专利局小职员爱因斯坦和两个朋友在伯尔尼自发组建"奥林匹亚科学院"：共读马赫、休谟、庞加莱，然后激烈争辩。没有权威、没有学位、没有观众，只有"把问题逼到墙角"的友谊。三年后，狭义相对论诞生。

**Olympia** 想复刻那种**机制与氛围**：一个本地优先的多智能体辩论系统。你提出议题，数位立场不同的"院友"按正式辩论协议与你交锋，所有论证被记录、沉淀、跨会追踪。当前是 P0.5 阶段——CLI 最小验证，先验证命门假设：**AI 能不能产出真异见，而不是礼貌的补充**。

## 核心思路：异见来自认知分工，不是性格表演

**三条设计宪法**（不可妥协）：

1. **异见优先于附和**——附和是这个产品的失败态。
2. **论证优先于口才**——发言必须拆成"主张—担保—证据—限定—保留"的可检验结构，修辞不能替代理由。
3. **记忆优先于单轮对话**——院会是连续的，立场快照和悬而未决的分歧被持久保存。这是它和聊天窗口的根本区别。

**功能席位，而不是名人扮演**。不让 Agent 扮演爱因斯坦本人——那会退化成口音模仿和名言拼贴。每个席位是一种认知功能：

| 席次 | 认知功能 | 强制规则 |
|------|----------|----------|
| 建构者 | 提出大胆统一的解释 | 必须给出可被反驳的命题，禁止只谈"可能性" |
| 怀疑者 | 找反例、查边界条件 | 每轮至少一个具体反例或"若成立则应看到 X" |
| 追问者 | 概念清理 | 不持立场只提问，问题必须指向具体语句 |
| 书记官 | 结构化纪要 | 不辩论，只做忠实压缩与可追溯引用 |
| 魔鬼代言人（轮值） | 为最弱方辩护 | 共识即将形成时被强制指定 |

**协议库才是护城河**。Agent 框架人人能写，独特资产是首批内置的六套辩论协议：**钢铁人开场**（反驳前先以对方认可的最强形式复述对方论点）、**盲立场轮**（互相看到内容前独立提交立场，防群体思维）、**图尔敏骨架**（JSON Schema 约束五字段输出）、**苏格拉底诘问**（一次只问一个问题，直到定义崩塌）、**正题—反题—合题**（合题必须写明吸收了反题的什么，禁止各打五十大板）、**停战规则**（未解分歧写入悬案簿，不许假装解决）。

## 具体实现步骤

**1. CLI 先行，UI 让路。** 内核在无界面下可测可回放，避免被界面开发拖住。三条命令走完闭环：

```bash
pnpm olympia debate "自由意志是否存在" --rounds 3   # 开一场院会
pnpm olympia replay transcripts/<file>.json         # 回放
pnpm olympia minutes transcripts/<file>.json        # 查看纪要
```

**2. 确定性状态机 + LLM 只在节点生成。** 流程必须是代码（可测试、可回放、可评估），模型只负责在回合节点上生成内容。采用**中心化导演模式**：只有核心引擎能调用模型、推进回合，Agent 之间不能互相 spawn——这防住了多智能体系统最常见的失控：自嗨循环、token 爆炸、议题漂移。

**3. 成本控制内建。** 席次分模型档位（建构者用强模型，书记官用便宜模型）、轮数硬上限、每场院会显示 token 与估算费用、盲立场轮并发调用省墙钟时间。

**4. P0.5 spike：先打命门。** 整个项目的生死问题是"异见质量"——如果 AI 院友只会变着花样附和，后面的一切都白搭。所以第一个里程碑不做 UI、不做记忆，只做 CLI 跑真实院会，用五组议题fixture + 验收 rubric 检验异见是否成立。目前已跑完两轮"自由意志是否存在"真实院会，留下完整 transcript 待人工验收，通过后进入 P1（年鉴记忆、立场追踪）。

## 参考了什么思想

- **奥林匹亚科学院史实**（1902–1905 伯尔尼）：爱因斯坦、索洛文、哈比希特的读书会——项目名与氛围的来源，复刻机制而非人物。
- **图尔敏论证模型**（Stephen Toulmin，《论证的使用》）：主张/担保/证据/限定/保留五字段，是"论证优先于口才"的可执行形式。
- **苏格拉底诘问法**：连续追问直到定义崩塌，追问者席位的原型。
- **辩证法**（正题—反题—合题）：强制三轮推进，且禁止伪综合。
- **钢铁人原则**（Rapoport 规则，丹尼特在《直觉泵》里推广）：先复述到对方满意再进攻，是对抗"稻草人谬误"的工程化。
- **协商民主与对抗式协作**：异见不是噪声而是机制——和 AnimaEVA 篇一样，这里也把认知科学翻译成了可运行的系统约束。
