AI 信息过载的解法通常是：再订一份 newsletter。但别人的策展永远隔着一层——粒度不对、口味不对、时机不对。我想要的是：每天早 8 点，一份**按我的栏目设计、由 AI 现场调研现场撰写**的 AI 前沿日报，躺在邮箱里。

[frontier-report](https://github.com/RUI-debug769/frontier-report) 就是干这个的（已开源，MIT）：headless Claude 深研当日（当周）AI 前沿 → 严格 JSON 契约校验 → 暖陶暗色 HTML（邮件客户端兼容）→ SMTP 直投。**纯 Python 标准库，零第三方依赖**，Windows / Linux / macOS 通吃。

## 核心思路：确定性代码管流程，模型只管内容

整个系统是一条把"不可靠的模型输出"夹在"可靠的确定性代码"中间的流水线：

```
cron / 计划任务  →  构造 prompt（注入日期/聚合最近 7 份日报）
→  headless `claude -p`（WebSearch/WebFetch 现场深研）
→  JSON 三级提取（容忍 repr / 代码围栏 / 遥测噪声）
→  严格 schema 校验（失败 exit 1，宁可不发）
→  渲染纯文本 + 暖陶暗色 HTML（table 布局 / 全内联 CSS / 640px）
→  存档 .md → SMTP STARTTLS 投递（失败重试 3 次，退避 15s/45s）
```

两条铁律：**契约失败宁可不发信**（一份坏日报比没有日报更糟——它会消耗你的信任）；**投递失败不消耗状态**（没送出的概念复习不算数）。

日报内容：今日速览 + 四栏目（领军人物 / 公司与产业链 / 重大事件 / 政策监管）+ 热门 Paper 技术 + 每日一概念 + 值得深读，约 5 分钟扫读；周报聚合最近 7 份日报做跨日综合，周末深读。

## 最有意思的部分：间隔重复学习机

"每日一概念"不是随机挑个名词解释，而是一台完整的学习机，思想提炼自**墨墨背单词团队的 KDD 2022 间隔重复调度论文**：

- 每个概念记录一个**记忆半衰期 h**，间隔 Δ 天后回忆概率约为 2^(-Δ/h)；
- 当 Δ ≥ h（你**即将遗忘**它）时，该概念自动排入当日报纸，以"回忆提示 + 精要重述"复推；
- 每次复推后半衰期 ×2.3——复习间隔自然拉宽：1 → 2.3 → 5.3 → 12 → 28 → 64 天。

关键在于分工：**调度由 `concepts.py` 确定性完成**（状态就是数据目录里的一个 concepts.json），模型只负责生成复习文本。学习科学管什么时候学，LLM 管怎么讲。

## 具体实现步骤

**1. 零依赖起步。** 纯标准库（urllib/smtplib/json/tomllib），任何装了 Python 3.11+ 的机器 `pip install` 即用——依赖越少，定时任务在裸 cron 环境里死得越慢。

**2. 防模型任性三级提取。** headless 模型输出从来不干净：先按严格 JSON 解析，失败则剥代码围栏，再失败则提取首个 JSON 对象——三级兜底之后仍失败，才判契约违反。

**3. 邮件 HTML 的复古工程。** 邮件客户端的 CSS 支持停留在 2003 年：table 布局、全内联样式、640px 定宽，暖陶暗色配一套纯文本 alternative。`frontier-report sample` 随时本地生成样例对版。

**4. 工程细节一次到位。** `doctor` 命令体检（claude CLI / SMTP / 数据目录一次看清）；配置四级优先级（CLI > 环境变量 > config.toml > 默认）；Windows 下回退读注册表持久化环境变量；三种调度样例（cron / systemd timer `Persistent=true` 错过补跑 / Windows 计划任务）。

**5. 生产接管。** 本地实例每天 08:00 日报、每周六 08:30 周报（聚合前 7 天），产出归档进 Git 仓库可追溯。

## 参考了什么思想

- **Unix 哲学**：做一件事并做好；文本进文本出；调度交给 cron 而不是自己造守护进程。
- **契约式设计（Design by Contract）**：模型输出是不可信输入，schema 校验是闸门，校验失败立即 exit 1。
- **防御性编程**：三级 JSON 提取、SMTP 退避重试、投递失败不消耗状态——默认外部世界一定会出错。
- **间隔重复学习科学**：艾宾浩斯遗忘曲线的现代可计算版——墨墨 KDD 2022 的半衰期回归模型。
- ** Newsletter 工艺**：暖陶暗色 + 复古 table 布局，功能约束下的美学。

## 现状与待补
