同一张参考图、同一个模型（Seedream 5.0 Pro）、同一个角色，为什么第一版生成得"不像她"，而第八版"就是她"？答案不是模型变聪明了，而是提示词经过了 8 个版本的迭代——每一版都针对上一版画面里**具体看到的问题**，改一句或一段提示词，再验收。

这篇记录整个过程：每版改了什么、为什么这样改有效、效果如何。文末附完整 PDF 复盘下载（含三列对照表：我的原始指令 → Claude 的思考链 → 落地提示词）。

## 一、先对齐目标：效果变好的第一步不是写 prompt

初始需求是"基于人设图批量生成游戏/博客立绘"，第一版方案按惯性设计了 16 张、四个差分维度（姿势表情/服装/场景/景别）。我在验收中连续三次收窄范围：

- **"画风不一样，AI 味太重，要和原图一样"**——推翻通用风格词；
- **"表情也不需要其他表情，和原图一致即可"**——砍掉表情差分；
- **"唯一需要改变的是动作，并且动作要符合本人的风格"**——砍掉服装/场景/景别，只保留动作差分，并给出完整角色圣经：黑白漫画网点风、"松弛的冷"气质、低张力动作规则（动作不解释动作、先眼后头、停顿大于过渡、重心说话、不对称、延迟响应）与禁区（不卖萌、不歪头、无表演感预备动作）。

> 差分维度默认全部锁定，只放开被点名的那一个。所谓 prompt engineering，一半是工程，另一半是把"一致性"这个真实目标跟需求方对齐。

## 二、版本迭代总表

| 版本 | 画面里看到的问题 | 提示词怎么改 | 结果 |
|------|------------------|--------------|------|
| v1 | 初始方案 | 自撰"赛璐璐/商业立绘"风格词 | **推翻**：画风跑偏 |
| v3 | 风格不对、AI 味重 | 角色圣经入 prompt：锁脸/锁表情/锁画风 | 画风过；网点密+手错 |
| v4 | 点多、手部错误 | 网点分区；手部正面解剖表述；负面块 2 词 | 通过，放量 |
| v5 | 06 手指缺截、疑似多痣、点仍多、手不够草、背景空 | 痣交回参考图；网点极少；草稿手；桌面背景；纯黑白阴影 | 显示器太小、痣争议 |
| v6 | 背景不够极客 | 极客工作站背景（双暗屏/机械键盘/耳放/垂线） | 01 通过 |
| v7 | "手再草稿一点" | 速写级手部；为风格统一全量重跑 | 腿椅融合、手仍偏具体 |
| v8 | 腿椅一体、手偏具体、阴影质感 | 白缝图底分离；袖口藏手；纯黑实色阴影 | **定稿** |
| v8+ | 05 手部问题 | 单点修复：手撑扶手获得接触锚点 | 通过 |

两个插曲也值得记下：08 的提示词触发文本敏感词审核（HTTP 400），改写身体部位措辞后补跑成功；"泪痣事件"——一度以为模型多画了痣，核对后确认原图即有两颗，避免了一次错误"修复"。

## 三、五次转折：问题 → 改法 → 为什么有效

### 3.1 v1 → v3：不要"描述"风格，要"锁定"风格

**问题**：v1 的图是精致的彩色二次元立绘，而参考图是黑白漫画。

**改法**——自撰的风格词整段删除，换成复刻式锁定：

```text
删除：STYLE = "精致二次元游戏立绘风格，赛璐璐上色，商业级立绘质量……"

改为：STYLE_LOCK = "画风必须完全复刻参考图：纯黑白漫画，高对比，大留白，
网点纸质感，与参考图相同的线条粗细与排线方式。不要彩色，不要灰度厚涂，不要3D感。"
```

**为什么有效**：风格词是强指令——"赛璐璐""商业立绘"会把模型拉向训练分布里的通用彩色二次元，强度盖过参考图。把风格判断权完全交回参考图之后，画风此后再未跑偏。

### 3.2 v3 → v4：网点是分区资源；手部用正面表述

**问题**：画风对了，但全屏都是网点颗粒，手部结构错误。

**改法**：先调研（Sider 的 Seedream 瑕疵指南、GitHub voftik/orimg 的提示词参考），确认模型特性后下两处补丁：

```text
网点："仅出现在阴影和深色区域，密度与参考图一致；亮部、皮肤和留白背景纯白干净。"
手部："每只手五指分明、关节比例自然"（正面表述，非禁令）
末尾：Negative Prompt: 多余手指，全屏噪点。
```

**为什么有效**：漫画技法里网点本来就是分区使用的（阴影/灰部专用），笼统写"网点质感"等于允许模型全屏铺点。手部则相反——该模型长负面清单生效不稳定，正面解剖描述 + 末尾只挂两个具体名词的组合比堆禁令可靠。

### 3.3 v4 → v5/v6：文字点名反而制造错位；背景要"她的世界"

**问题**：全量复查发现 06 中指缺截、7 张疑似多出左泪痣、网点仍偏多、手部不够草稿、纯白背景不像她。

**改法**：

- **痣**：删掉"左眼下方有一颗小痣"，改为"面部细节完全以参考图为准"；
- **网点/手**：网点压到"极少、密度绝不超过参考图"；手部改草稿线条；
- **背景**：纯白虚空 → 她的桌面空间，再升级为极客工作站（支架臂双大屏暗屏、机械键盘、解码耳放、黑色杯子、垂落线材），屏幕保持暗色以符合人物气质。

**为什么有效**：参考图能表达的特征（痣的位置、小道具细节），文字点名只会引入第二个信息源——两个来源不一致时模型就自由发挥。背景同理：人物的"气质"需要环境支撑，空背景等于放弃了这部分表达。

### 3.4 v7 → v8：藏手优于描手；黑白图底必须分离

**问题**：v7 把手部推到"速写级"仍偏具体，且出现"大腿和凳子成为一体"。

**改法**——第二轮调研后的三处结构修改：

```text
SEPARATION = "外轮廓线加粗加重；深色外套与深色椅子之间必须有一条清晰的白色轮廓缝隙；
任何两个深色块之间都用留白或白边明确分隔。"
HANDS = "袖口略长盖住手腕，可见手指只用两三笔概括；拿东西时让物件挡住大部分手指。"
阴影 = "以纯黑实色涂黑为主，网点只用于小面积中间调、密度极低。"
```

**为什么有效**：黑白高对比下，两个相邻深色块在模型眼里没有边界——必须显式要求"白缝"来制造图底分离。手部的终极解法不是把画法写得更细，而是减少需要画对的内容：袖口、物件、口袋都是合规的"藏"。阴影回到漫画的正确明暗结构：纯黑实色块为主，网点只负责中间调——之前网点过多，本质是把网点当灰度用了。

### 3.5 v8+：单点修复——给手一个接触锚点

**问题**：05"起身到一半"的手部仍出错。只改一句动作描述：

```text
改前："双手刚离开扶手"
改后："双手仍撑在扶手上用力支撑，重心开始前倾"
```

**为什么有效**：悬空、无支撑、无遮挡的手是生成错误的高发区；手与扶手接触后，位置、角度、遮挡关系全部有了锚点。而且"手撑扶手先发力"本来就更符合角色"慢起慢停"的力学——正确的物理描述同时是正确的生成策略。

## 四、指令 Loop：让改进收敛的七条纪律

提示词改动只是半个故事，另一半是迭代的纪律：

1. **先试跑 1–2 张验收，再放量**。测试图选风险最高的姿势，验收通过才跑全量；测试产物直接并入正式集。
2. **幂等脚本**：已存在且合格的文件自动跳过，失败重试 3 次，批量后台运行。中途改需求先停批量止损。
3. **一次只改已观察到的问题块**，每版保留归档，任何修改可回溯。
4. **提示词未变的条目绝不重跑**——同 prompt 重新生成会因随机性带回已通过的回归。
5. **验收也可能误判**：先核对原图再改提示词，别把对的改丢。
6. **敏感词是文本审核，不是图像问题**：换措辞即可，不动画面设计。
7. **三层持久化**：方法写入长期记忆；参考图+脚本+产出落持久目录；API 密钥不落盘。

## 五、可复用规则清单

1. 锁风格，不描述风格——"完全复刻参考图"+逐项锁定视觉特征。
2. 差分维度默认全锁，只放开被点名的那一个。
3. 参考图能表达的特征交给图，不在文字里点名。
4. 网点分区且密度锚定参考图；阴影以纯黑实色块为主，网点只做小面积中间调。
5. 藏手优于描手：袖口盖腕、物件遮挡、插兜；必须露手时给接触锚点。
6. 黑白图底分离：主体外轮廓加粗 + 深色块之间强制白色轮廓缝隙。
7. 负面块最多 1–2 个具体名词，优先正面重述。
8. 多参考图分工：角色锚管长相与画风，款式/场景锚管其余，prompt 只声明要替换的部分。
