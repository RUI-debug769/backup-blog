# 个性化 ACG 文章封面设计

日期：2026-11-06

## 目标

为 MUR DOS LOG 当前 10 篇公开文章建立固定、可复现、符合站长偏好的 ACG 封面。首页文章卡片、文章详情头图与分享图使用同一张图片；封面只承担展示与进入当前文章的既有交互，不跳转第三方网站。

## 已确认决策

- 全部替换现有 8 张封面，并为另外 2 篇补齐封面；旧图不删除，仍可从版本历史恢复。
- 建立本地精选图库，不使用在线随机接口，不在读者浏览器中发起第三方图片请求。
- 当前 10 篇逐篇明确绑定不同图片；新文章可自动获得固定封面，也可在文章 frontmatter 中手动覆盖。
- 图片为适合公开展示的全年龄日系二维插画，优先呼应计算机、AI、数学、逻辑学、哲学、物理学，并融入 Neuro-sama 系、虚拟歌手、《CLANNAD》《HELLO WORLD》等明确偏好。
- 原作品页、作者、来源网站和检索标签保存在来源清单中，不在封面或正文增加站外链接。

## 图库与内容边界

图库首批固定为 16 张横幅素材，保证数量大于当前文章数，给新文章留出固定分配空间。候选图片来源优先为可逐张核实作品信息的 ACG 图片站与原作者作品页；聚合站不代表图片具有统一再发布授权，不能把“可以下载”写成“已获授权”。来源清单必须区分已知作者、未知作者和授权信息，不得编造。

每张图片入选前逐一检查：

1. 全年龄、无露骨内容、无令人不适的构图；
2. 日系二维风格，符合“有灵魂的个性化极简”，避免通用素材感；
3. 与智慧主题或已确认角色偏好有可见关联；
4. 横幅裁切后主体完整，文章标题覆盖时仍有可读性；
5. 作品页、作者与来源信息可追溯，无法确认来源的候选不采用。

## 数据结构与分配规则

在 `src/data/` 新增封面图库数据，条目包含稳定 ID、文件名、替代文本、主题标签、来源网站、原作品页、作者和授权备注。图片原始素材统一放入 `src/assets/images/post-covers/`，解析后向文章数据写入相对路径 `../../assets/images/post-covers/<文件名>`，使源码模式与 npm 包模式都能命中现有图片加载器并生成响应式资源。另设文章 ID 到图库 ID 的显式映射，覆盖当前全部 10 篇，且当前映射不得重复使用图片。

在构建期工具中提供唯一封面解析函数，优先级如下：

1. 文章 frontmatter 的非空 `image`：视为作者手动覆盖；
2. 当前文章的显式图库映射；
3. 对文章 ID 做稳定哈希，在按稳定 ID 排序的图库条目中选取，保证同一文章 ID 与同一图库版本在不同构建与部署中得到同一结果。图库内容或顺序的维护属于一次显式版本变更，必须重新核对自动分配结果；新文章稳定后建议补写显式映射，避免图库扩展影响旧文章。

现有 8 篇的旧 `image` 字段随本次替换移除，使显式图库映射生效；其余文章不需要为了默认值增加 frontmatter 字段。空图库、无效映射、当前文章重复用图和缺失文件属于构建配置错误，应在构建期明确报错，而不是悄悄退回随机图或第三方接口。文件存在性通过源码资源与项目资源的静态 glob 双重校验，不用 `process.cwd()` 读取主题自有文件。

## 数据流与页面一致性

封面解析接入 `getRawSortedPosts()` 的统一数据装配过程。首页、规范文章路由、旧永久链接路由、RSS 与其他读取排序文章的消费者因此共享同一个 `entry.data.image`。

本地图片沿用现有 `PostCard` 与 `ImageWrapper` 响应式图片管线，生成 AVIF/WebP 候选并保留尺寸信息，避免新增客户端脚本、网络依赖或布局偏移。详情页的 `og:image`、分享海报封面和文章卡片均读取解析后的同一字段。封面在列表中仍进入当前文章，不添加作品站跳转。

## 错误处理

- 构建前校验图库 ID、文章映射、文件存在性与当前文章覆盖完整性；重复 ID、引用不存在的图或当前文章未覆盖均使校验失败。
- 下载与图像转换只发生在选图阶段；正常构建与读者访问不依赖第三方服务。
- 图片加载失败沿用现有卡片的加载结束处理，不增加在线回退；通过本地文件校验与构建产物检查预防该状态。
- 不修改正文、intro、看板娘、Banner 池、日报集合及思考集合。

## 验证与成功标准

1. 图库与映射校验通过，当前 10 篇都有唯一且明确的封面，重复构建结果不变。
2. `pnpm format`、`npx astro check`、相关单元测试、文章列表与文章页 Playwright 测试、无障碍测试及完整构建通过；若仓库已有失败，逐项区分既有问题与本次新增问题。
3. 浏览器检查桌面与手机尺寸下的列表、详情、明暗主题及站内导航；同一文章各处图片一致，刷新不变。
4. 图片均为本地资源，页面不因封面请求 ACG 网站；图片不携带站外链接。
5. 全部 16 张入库图片都经过内容、来源与横幅构图检查，其中 10 张当前分配另逐篇核对语义；来源清单中的作品页与作者信息可追溯，无虚构授权声明。
6. 未得到明确确认前不提交；提交使用仓库约定的 Conventional Commits 与精确暂存，不使用 `git add -A`。
